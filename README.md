# Game_Final_Project

Final Project Update:
A game where you move a cue ball into a goal area. This game features a User Interface that allows the user to go to the level in the game, the (non-functional) leaderboard menu and the settings menu with options to switch between menus with ease. This project had many challenges. After the inital database creation and connectivity with Postman, connecting the database to the Godot interface proved significant difficulty throughout the later duration of the project. Picking a new application to create this project was not a great idea. Learning the syntax of Godot while also trying to create a functional backend proved very difficult. Using a application we were more confortable with would have allowed the project to have continued on track. 
If we were to revisit this game, an addition could be having multiple different levels and obstacles to show more variety and enjoyability while playing.
